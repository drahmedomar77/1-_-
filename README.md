# ذِهْن — تحدّي العقل والنطق

تطبيق ألغاز عربية أصلي للجوال، مبني على فكرة «دفتر التحديات»: أسئلة قصيرة في المنطق والكلمات والأنماط والحساب والملاحظة، مع مسار متدرج، تحدي يومي، سباق دقيقة، وتمارين نطق جانبية اختيارية. لا ينسخ التطبيق اسم «شعلة» أو تصميمه أو أسئلته.

## ما يتضمنه المشروع

يحتوي الإصدار الحالي ١٦ لغزاً أساسياً موزعاً على سهل ثم متوسط ثم صعب، وتمرينين إضافيين للنطق. كل سؤال أساسي يعطي تلميحاً وشرحاً. يُحفظ التقدم محلياً: الإكمال والنقاط والنجوم والشارات والسلسلة اليومية وأفضل نتيجة، مع إعدادات الصوت والنطق والاهتزاز. تحدي اليوم يعطي نقاطاً مرة يومياً؛ وسباق الدقيقة يختار عشرة أسئلة أساسية ولا يُدخل تمارين النطق.

تمرين النطق تجربة مطابقة نصية فقط: ردّد العبارة ثم استخدم ميكروفون لوحة مفاتيح الهاتف لتحويل الكلام إلى نص، أو اكتب الإجابة يدوياً. التطبيق لا يسجل الصوت ولا يحلله أو يرسله، ولا يقيس مخارج الحروف أو مستوى النطق طبياً. قد تعالج لوحة المفاتيح أو خدمة الإملاء الصوتي على الجهاز الصوت وفق إعداداتها الخاصة. نتائج ذِهْن للترفيه والتدريب ولا تمثل اختبار IQ معيارياً.

## المتطلبات والتشغيل المحلي

يتطلب المشروع Node.js وpnpm. بعد تنزيل ملفات المصدر:

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm dev:metro
```

`pnpm dev:metro` يشغّل معاينة الويب على المنفذ 8081. لتجربة Android عبر Expo Go محلياً استخدم `pnpm exec expo start --port 8081` ثم امسح رمز QR باستخدام Expo Go؛ قد تحتاج إلى تسجيل الدخول إلى حساب Expo. حزمة الإعلانات أصلية ولا تعمل في Expo Go أو الويب، ولذلك لا تظهر الإعلانات في المعاينة. فحوص المصدر: `pnpm check` و`pnpm test`، وتصدير الويب: `pnpm exec expo export --platform web --output-dir dist-web`.

## إنتاج APK Android

أُعد `eas.json` بملف `preview` من نوع APK للاختبار الداخلي و`production` من نوع Android App Bundle للنشر في Google Play. **لا يحتوي هذا الأرشيف على APK مُنتج أو مُختبر بعد**؛ يلزم إجراء Android Build من لوحة المشروع Dashboard على إعداد مقبول وحساب/بيانات توقيع صالحين. بعد نجاح البناء حمّل ملف APK وثبّته على جهاز Android واختبره. لا ننشئ APK native داخل Sandbox. يمكن لصاحب المشروع استخدام EAS CLI من حساب Expo الخاص به خارج Manus إذا أراد؛ قد يطلب إعداد مشروع EAS وبيانات توقيع.

لا ترفع ملفات التوقيع أو `.env` أو الأسرار إلى مستودع عام. قبل نشر Google Play، أعد ملف AAB وسياسة الخصوصية وإفصاحات البيانات المناسبة.

## إعداد AdMob والإعلانات

تستخدم البنية `react-native-google-mobile-ads` مع Google UMP. تتحقق النسخة الأصلية من حالة الموافقة قبل طلب الإعلان، ثم تطلب إعلانات غير مخصصة. البانر على الرئيسية فقط، والإعلان البيني عند نهاية فصل، والإعلان بمكافأة لاستعادة محاولة بعد نفادها إذا اختاره اللاعب. لا يُعرض إعلان أثناء التفكير.

لا يحتوي المشروع افتراضياً على معرفات ناشر فعلية، ولذلك لا يولد دخلاً حتى تُنشئ تطبيقاً ووحدات إعلانية في حساب AdMob وتضيف القيم التالية كمتغيرات بيئة للبناء:

```text
ADMOB_ANDROID_APP_ID=ca-app-pub-...~...
ADMOB_IOS_APP_ID=ca-app-pub-...~...                 # عند إضافة iOS
EXPO_PUBLIC_ADMOB_BANNER_UNIT_ID=ca-app-pub-.../...
EXPO_PUBLIC_ADMOB_INTERSTITIAL_UNIT_ID=ca-app-pub-.../...
EXPO_PUBLIC_ADMOB_REWARDED_UNIT_ID=ca-app-pub-.../...
```

لتجربة Google Test Ads على بناء تطويري فقط، أضف `ADMOB_USE_TEST_ADS=true` إلى بيئة البناء. لا تنشر هذا الوضع بوصفه نسخة مدرة للدخل؛ احذفه وأدخل المعرفات الحقيقية قبل الإصدار. معرّفات التطبيقات الاختبارية الافتراضية معرفات Google التجريبية، ووحدات الإعلان لا تعمل افتراضياً. `.env.example` نموذج بقيم فارغة وليس بيانات AdMob.

قبل الإطلاق التجاري أنشئ سياسة خصوصية، وأكمل إفصاحات Google Play، وراجع إعدادات موافقة UMP والجمهور والعمر وسياسات الشبكة. العائد غير مضمون ويتوقف على الجمهور والبلدان والتفاعل والامتثال للسياسات.

## رفع المصدر إلى GitHub

Mobile Dev يحتفظ بمستودع التطبيق الأساسي ضمن Manus، ولا يُحوَّل مستودعه إلى GitHub مباشرةً من هذا المسار. ارفع الأرشيف المصدر يدوياً: أنشئ مستودع GitHub جديداً (يفضل Private كبداية)، فك ضغط `thnapp-source.zip`، ثم نفّذ داخل المجلد:

```bash
git init
git add .
git commit -m "Initial zihn app source"
git branch -M main
git remote add origin https://github.com/YOUR-ACCOUNT/YOUR-REPO.git
git push -u origin main
```

الأرشيف لا يتضمن `node_modules` أو `.git` أو `.env`، ويتضمن `pnpm-lock.yaml` والأصول اللازمة لإعادة تثبيت الاعتماديات. لا تضف مفاتيح توقيع Android أو الأسرار إلى GitHub.

## بنية المشروع

- `app/(tabs)/index.tsx`: نقطة دخول Expo Router.
- `app/(tabs)/_layout.tsx`: تخطيط تبويب واحد يخفي شريط القالب.
- `components/play-app.tsx`: شاشات التطبيق ومنطق الجولات.
- `data/puzzles.ts`: بنك الأسئلة الأصلي مع الحل والتلميح والتفسير.
- `lib/game-state.ts`: الحفظ والتقدم ومطابقة الإجابات العربية.
- `lib/ads.ts`: AdMob وUMP على Android؛ `lib/ads.web.ts` بديل صامت للويب.
- `assets/images/`: أيقونات Android وExpo.
- `tests/puzzles.test.ts`: اختبارات سلامة البنك والتدرج ومطابقة العربية.
- `app.config.ts` و`eas.json`: إعداد التطبيق وحزم APK/AAB.
- `plan.md` و`TODO.md`: مواصفات المنتج وحالة التسليم.
